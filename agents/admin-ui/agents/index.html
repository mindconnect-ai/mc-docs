Agents

The Agents section manages agent definitions. An agent is system prompt + LLM config + tools.

Agent list​

The list shows every agent. From here you can:

  • New Agent — create a new agent definition.
  • Copy — duplicate an existing agent as a starting point for a variant.
  • Delete — remove an agent.

Click an agent to open its detail view.

Creating & editing an agent​

The agent form lets you set:

  • Name and description.
  • System prompt — the agent's role and instructions.
  • LLM Config — which model it uses, picked from your LLM Configs (e.g. agent-default, claude-default).
  • Tools — the tools the agent may call (see below).

Editing is the same form in "edit" mode; Copy pre-fills it from an existing agent.

Configuring tools​

In the agent detail view you manage the agent's tool list — add the tools it's allowed to call (e.g. web_search, file_read, run_agent) and remove ones it shouldn't have. The tool catalogue itself lives in the Tools section.

Sessions​

The detail view also lists the agent's sessions (conversations). Here you can:

  • New Session — start a fresh conversation with this agent.
  • Open — continue an existing session where you left off.
  • Delete — remove a session.

Opening or starting a session takes you into the chat view, where you see streamed responses, tool calls and sub-agent runs, and can inspect working memory, traces, todos and the workspace.

  • Sub-agents — how one agent calls another.

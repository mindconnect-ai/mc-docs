How sub-agents work

The model picks a sub-agent through a tool call:

run_agent("web-researcher", "Research Qdrant")

The sub-agent runs in its own session — own prompt, tools and model — does its work, and returns the result. Sub-agents can call sub-agents recursively.

Why delegate?​

  • Decompose complex tasks into focused sub-tasks.
  • Parallelism — several sub-agents work at once.
  • Specialization — each sub-agent has a tailored prompt and toolset.
  • Smaller main context — the orchestrator only sees results, not every intermediate tool call.
